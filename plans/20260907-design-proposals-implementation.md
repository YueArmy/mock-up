## 共通要件
- 訪問者: SNS等で知った、作品・作者に興味を持つ個人、および展示・取材・協業を検討する人。
- ゴール: 作品性と作り手への信頼を伝え、問い合わせへ。EC機能は含めない。
- ナビ: Home / About / Works / Contact、ページ内Newsletter。UIは日本語、英字は見出し補助。
- 内容: 代表作品3〜6点、素材→完成品、作り手紹介、制作の考え、問い合わせ、ニュースレター。
- 作品写真: 既存mock-upの資料画像を優先。onlyyuuka-hpの素材は出典を記録し、作者本人の写真と確認できない人物は使わない。
- 生成写真: 写真イメージとして表示し、実作品/実アトリエと混同させない。imagegenスキル＋画像担当サブエージェントを利用。
- サンプルのフォームは外部送信/永続保存なし。入力検証と確認画面を実装。実稼働は本番要件に記載。
- 相対URL、noindex、画像寸法、適切なalt、見出し階層、フォーカス、reduce-motion、モバイルメニュー、キーボードで閉じられる詳細ダイアログ。

## デザイン
### A 布の小さなギャラリー
作品鑑賞→素材→作者→相談。大きな明朝とセリフ、アイボリー、茶、作品の非対称展示。写真を一枚大きく配置。
### B 作り手のアトリエ
作者の制作姿勢→工程→作品→相談。手元の写真、生成りとセージ、親しみのあるノートの構成。根拠のない経歴は載せない。
### C 布をめぐる編集誌
素材と形の変化→作品の読みもの→作者→相談。大きな誌名、罫線、番号、ローズ系の色面とグリッド。元布の写真がないため偽のBefore/Afterは作らない。

## モーション
写真リンクの軽い拡大と矢印移動、短いhoverだけ。パララックス、強制スクロール、連続アニメーション、読み始めを待たせる演出なし。

## 素材・運用整理
準備ページにコンテンツ粒度、必須/後日、必要素材と枚数、確認担当、納品条件、未確定の本番運用を掲載する。経歴・費用・納期・実績は未確認値で埋めない。

## 検証と提出
ローカル静的サーバー、agent-browserで表示確認。自動検証は実リンク/画像読込、横はみ出し、filter、detail、menu、FAQ、問い合わせ確認、Newsletter確認を対象。ページ表示PDFとZIPを作成。
Git pushと新規公開はこの依頼で明示承認されていないため実施しない（main pushは自動公開を伴う）。ローカル閲覧・PDF・ZIPまで完成させる。

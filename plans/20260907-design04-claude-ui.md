# Design 04 — Claude DesignのUIを実装

## 目的
Design 01「布の小さなギャラリー」のコンセプトを引き継ぎ、Claude Designで新たなUIを制作してから独立したDesign 04として実装する。

## 制作順
1. 公開中のDesign 01の画面・作品画像・コピーをClaude Designへ渡す。
2. ユーザーの追加指示に従い、画像生成でUIイメージを先に制作。完成画像をClaude Designへ添付してレイアウト基準にする。
3. Claude DesignでHome・About・Works・ContactのUIを制作し、実表示を確認する。
4. 完成したUIを基準に、既存の静的サイトと同じ方式で4ページを実装する。
5. 比較ページにDesign 04への導線を追加する。
6. Computer UseでPC・スマホの表示とメニュー、作品詳細、絞り込み、フォーム確認を検証する。
7. 指定リポジトリにpushし公開反映を確認する。

## 条件
- 作品主役、自然光、生成り・茶、広い余白。ECではなくアーティストの名刺サイト。
- 既存の作品写真とイメージ写真を区別し、未確認の経歴や作品仕様を追加しない。
- 送信・登録は確認画面までのサンプル。旧提案書への導線は復活させない。
- 既存3案のデザインを保持する。
- Claude DesignのプロジェクトURLと採用したUIの特徴を記録する。

## Claude Design
https://claude.ai/design/p/fe7dba6d-9b76-4643-88a8-3609a8484c1a

画像生成を優先する追加指示を受け、最初のUI生成を一時停止。生成した参照画像を添付した後に4ページを制作した。

## 採用UIとHero修正
- Design 01の「作品を主役にしたギャラリー」を維持し、中央の明朝見出し、大きな写真、細い罫線、生成りと茶のUIへ。
- ユーザーの「Hero画像とタイトルが分かれている」違和感を反映。v2画像を生成しClaude Designへ添付して修正を依頼した。
- ヘッダー直下から連続した写真領域にタイトル・説明・CTAを重ねる。写真上部の壁面に明るいベールをかけ、布のある下側は質感を残す。
- スマホでは「暮らしに、」「もう一度物語を。」のまとまりで改行する。
- 参照画像はローカル `output/imagegen/design04-ui-reference-v2.png`、生成記録は `plans/20260907-design04-image-prompt.txt`。生成ツールはモデル指定パラメータを公開していないため、モデルの正確なバージョンは検証できていない。
- 比較ページのDesign 04プレビューは実HTMLを表示。生成画像を完成画面として掲載しない。

## 共通パーツ由来の差異を解消
ユーザーからお問い合わせ周辺の相違を指摘されたため、Claude Designの実DOM・インラインスタイル・実画面を読み取り、Design 04専用構造へ変更した。
- お問い合わせCTA：中央の見出し・説明・ボタンと、上下72〜140pxの余白。
- お便り：全面の背景色 #EFE7DA、左説明・右フォーム、入力欄と枠線ボタンを縦に配置。
- フッター：ロゴとナビ、著作権と注記の2段構成。
- Home制作紹介：横長の大きな写真、その下の2列の見出し・本文。
- About：全面写真→作者紹介2列→制作姿勢3列。
- Works：中央のカテゴリ、表示件数、写真と番号・作品名・説明・詳細リンク、常時読める3列の説明。
- PCの下層ページ見出しを固定2行から自然改行へ。スマホでは文節を保つ。
- ロゴの文字間隔はAGENTS.mdの0.08em、フォーム入力はスマホの拡大防止のため16pxを維持する。
- Shippori Mincho / Jostの字形を同梱し、OS標準フォント由来の差異も解消。掲載文字のサブセットとOFLライセンスを保存し、外部フォント配信への実行時依存を避けた。

# Claude Designによる提案資料の制作

ユーザーの指定により、公開済みの3案と提案書を資料としてClaude DesignのDocumentテンプレートで作り直す。

- A4縦8〜10ページを目安に、表紙、HPの役割、3案の実画面と狙い、掲載内容、必要素材、公開準備を整理する。
- 既存事実とサンプルの区別を引き継ぎ、本人情報・費用・納期を捏造しない。
- Claude Designで生成後、全ページの文字、画像、表、ページ区切りを確認する。
- PDF書き出し可能な完成資料にし、指定GitHubの提出導線へ反映する。
- ユーザーの追加指示により旧Word/PDFとダウンロード導線を公開対象から削除する。旧版はローカルのoutput/retired-proposalに退避し、Claude Design内の旧版リンクも削除する。

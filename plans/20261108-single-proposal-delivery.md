# 1案の提出用公開

## 依頼
「布の小さなギャラリー」1案を提出できるように整え、GitHubへpushし、確認用リンクを渡す。

## 実装
- 最新のローカル確認版7ページを site/preview/ に配置する。支給画像5点のみ同梱する。
- 比較ページへの導線、制作メモ、内部のコピー検討ページへのリンクを提出版から除く。
- クライアント向けの確認事項ページを追加し、価格・仕様・受付条件・ショップ/SNS・ストーリー/方針の配置を整理する。
- 問い合わせは入力確認・文面コピーのみ。実送信・購入は未接続であることを明示する。
- サイト直下と従来の提案/比較の入口から、今回の1案へ案内する。過去案のファイルは保管する。
- README、公開対象のJS構文検証、既存の相対リンク検証を更新する。
- 元資料、ローカルの制作確認メモ、未完成の別案や別作業のplanは今回のcommitに含めない。

## 検証と公開
1. 差分と公開ファイルを確認し、JS構文・リンク・画像・アンカーを検証する。
2. PCとスマホで全ページの表示、メニュー、英語説明、FAQ、商品名引継ぎ、入力確認/修正/コピーを確認する。
3. 対象ファイルのみcommitし、mainへpushする。
4. GitHub Actionsの成功、公開URLのHTTP応答と実際の表示を確認する。
5. 提出用トップと確認事項のURLを渡す。

## 公開前の検証結果
- site/preview/に本体7ページ＋確認事項、支給画像5点を用意。内部の制作メモと比較導線は提出版から除去した。
- サイト直下、proposal.html、designs/index.htmlの案内先を今回の提出版に変更。過去案の個別ファイルは保持。
- site/全24ページの相対リンク・画像・アンカーと、CI対象の全5本のJS構文が正常。
- 提出版8ページを1440/390/320pxで確認（24ケース）。横はみ出し、画像エラー、H1重複、内部メモなし。
- スマホメニュー、商品名引継ぎ、英語説明、問い合わせ入力確認・修正・コピー、FAQ、旧入口3件の遷移を確認。ブラウザの警告・エラーなし。
- 価格・受付条件は保留のまま。個人の病歴、未確定の連絡先、元資料のリンクなどは提出版に含めない。
